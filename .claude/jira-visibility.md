# Jira visibility (outside this repository)

In the original SDLC control and visibility process, artifacts in `.wiz/<slug>/` were designed for a board. A Cursor Skill read planning generated by the kit (`prd.md`, `phases/phaseN.md`, and `P0XM0Y` milestones within each phase) and created issues via the Jira REST API, with this mapping:

| Artifact in `.wiz/<slug>/` | Jira issue |
|---|---|
| `prd.md` | **epic** documentation |
| each `phases/phaseN.md` | **task** child of the epic |
| each `P0XM0Y` milestone | **subtask** child of the phase task |

The plan's source of truth remained in Git (`.wiz/<slug>/`). Jira was the visibility layer for management — not a substitute for planning.

That skill and API calls **are not part of this repository**: there is no versioned skill, no export script, and no credential. Tracking here is `.wiz/<slug>/` + `/wiz-status`. This file records the process; it does not execute it.
